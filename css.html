CSS क्या है?

CSS का पूरा नाम Cascading Style Sheets है। CSS का उपयोग Website को सुंदर और डिजाइन करने के लिए किया जाता है।

CSS का पहला Code

body {
  background: lightblue;
}
यह CSS से Design किया गया Box है!

Text का Color कैसे बदलें?

h1 {
  color: red;
}

इस code से सभी h1 headings का रंग बदल जाएगा।

Background Color

body {
  background-color: yellow;
}

CSS में Padding

div {
  padding: 20px;
}

Padding से element के अंदर space मिलता है।

अब आगे क्या सीखें?

HTML और CSS के बाद JavaScript सीखकर Website को Interactive बना सकते हो।
