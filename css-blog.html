🎨 Learn CSS

CSS ka full form Cascading Style Sheets hai. CSS ka use website ko beautiful aur attractive banane ke liye hota hai.

CSS kya karta hai?

CSS se hum website ka color, font, size, background, spacing aur layout change kar sakte hain.

CSS Example

<style>

h1 {
    color: blue;
}

p {
    font-size: 18px;
}

</style>

CSS seekhne ke fayde 🚀

CSS seekhkar aap beautiful aur responsive websites bana sakte ho. HTML aur JavaScript ke saath CSS use karke professional websites create ki ja sakti hain.
