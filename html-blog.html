HTML ka full form HyperText Markup Language hai. HTML ka use website banane ke liye hota hai.

HTML kya karta hai?

HTML website ka structure banata hai. Isse hum Heading, Paragraph, Image, Button aur Link bana sakte hain.

HTML Example
